# 信源与采集边界

只抓取公开可访问内容，遵守 robots、服务条款和限速；不绕过登录、付费墙、验证码或反爬挑战。遇到 401、403、验证码或登录页时，不重试绕过，记录错误并结束该信源本次采集。

| `sourceClass` | 定义 | 正式报告规则 |
| --- | --- | --- |
| `official` | 平台、政府、物流商或 API 官方来源 | 可作为政策、金额、日期的主来源。 |
| `professional-media` | 有编辑责任的行业媒体或专业机构 | 可报道行业事件；政策、金额、日期优先回溯官方原文。 |
| `community` | 卖家社区、论坛或社媒 | 仅作异常信号，未独立证实不得写成确认事实。 |
| `aggregator` | 聚合转载、营销软文或来源不明内容 | 仅作发现线索，不进入正式日报。 |

新增 HTML 信源前必须确认入口公开可访问、采集被允许、发布时间与正文可提取、canonical 可识别，且连续抓取不会触发登录或验证码。
